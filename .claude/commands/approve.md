# Approve

Read the selection first. Only record an operator-supplied decision, actor and evidence reference. Run `node scripts/studio.mjs approve "<selection>" --actor="<person>" --evidence="<reference>" --decision=approved --json`. Rejection uses `--decision=rejected`. This records a decision made elsewhere. It does not obtain client consent.

When a name is ambiguous, list the candidates and ask. Never send or publish. Never answer from memory.
