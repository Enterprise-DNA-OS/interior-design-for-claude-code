# Weekly Review

Run `node scripts/studio.mjs attention --json`, `node scripts/studio.mjs delivery-chase --json`, and `node scripts/studio.mjs margins --json`. Write a Monday review: approvals to obtain, suppliers to chase, overdue tasks, and budget position by currency. Name the person when recorded. List missing owners as missing.

When a name is ambiguous, list the candidates and ask. Never send or publish. Never answer from memory.
